# libcrt
**libcrt** - C RunTime library.

## Description
This is a union of TheCRatTime's libraries with namespaces and import system.

### Features
- **Namespace**: all of functions starts with "Crt", to disable it, you can
define **CRT_NOT_USE_NAMESPACE** and include headers
from **unsafe/** directory.

- **Import System**: e.g. for include **mem/atexit.h** you don't write
**libcrt/mem/atexit.h**, you can define **CRT_IMPORT** (maximal value: 6)
with **"mem/atexit.h"** and only include **libcrt/crt.h** or
**libcrt/crt_import.h**.

- **C89**/**ANSI C** library code standard.
- **stb-style** library

### Provides...
The **libcrt** provides some tools:
- **Arena and Allocators**: you can found arena, debug and block allocator.
- **RLE and HEX**: tools that can compress data and encode string to hexadecimal format
- **Error handler**: **cerrors** with commands **cerrors.New(...)**.

You can found project by link `https://github.com/TheCRatTime/project_name`.

### Build
Needed:
- C Compiler
- CMake 3.10 and greater
- GNU Make

```bash
cmake -B build
cd build/
make
```
